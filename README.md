# Sepesha — Ride-Hailing Mobile Application

Sepesha is a ride-hailing platform with customer and
driver applications that connect passengers with drivers.

## My Contribution

My role focuses on maintaining and improving the existing
applications and managing Android releases.

- Application maintenance and troubleshooting.
- Improvements to existing functionality.
- Application updates and compatibility adjustments.
- Release preparation and deployment to Google Play.

## Technologies & Tools

- Flutter
- Dart
- Android Studio
- Google Play Console

## Applications

- **Customer App:** For passengers requesting rides.
- **Driver App:** For drivers receiving and managing requests.
